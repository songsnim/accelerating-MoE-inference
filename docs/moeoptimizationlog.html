타일링 (Tiling)

큰 행렬을 GPU가 한 번에 다룰 조각으로 쪼개서, 조각 하나를 빠른 메모리에 올려두고 재사용하는 것.

공유메모리

블록 안의 스레드들이 함께 쓰는 작은 고속 메모리(SM당 100 KB). DRAM보다 수십 배 빠릅니다.

병합 접근 (Coalescing)

워프의 32개 스레드가 연속된 주소를 읽으면 한 번의 전송으로 끝납니다. 흩어져 있으면 32번 갑니다.

점유율 (Occupancy)

SM 하나에 동시에 올라가는 워프의 수. 레지스터·공유메모리·스레드 수 중 먼저 걸리는 것이 상한입니다.

커널 융합 (Fusion)

이어지는 커널 둘을 하나로 합쳐, 중간 결과가 DRAM에 나갔다 오지 않게 하는 것.

산술 강도

바이트 하나를 읽어서 연산을 몇 번 하느냐. 낮으면 메모리가, 높으면 연산기가 병목입니다.

메모리 병렬성 (MLP)

동시에 비행 중인 메모리 요청의 양. 적으면 대역폭이 남아돌아도 못 씁니다.

부동소수점 순서

FP32 덧셈은 결합법칙이 성립하지 않습니다. 더하는 순서를 바꾸면 결과의 마지막 비트가 달라집니다.

개념 레지스터 타일링 — 메모리 계층의 한 칸 더 아래

RTX 3090은 SM당 공유메모리에서 사이클당 128바이트를 꺼낼 수 있는데 FP32 연산기는 128개 레인입니다. 값 하나 읽어 곱셈 한 번만 하면 연산기가 놉니다. 그래서 값을 레지스터에 붙잡아두고 여러 번 씁니다.

이전 — 스레드 1개 = 출력 1개

이후 — 스레드 1개 = 출력 4×4

    for (i) a[i] = As[p][ty*4 + i];   // 4회
    for (j) b[j] = Bs[p][tx*4 + j];   // 4회
    for (i) for (j) acc[i][j] += a[i] * b[j];   // 16회
